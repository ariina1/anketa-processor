\# Обработчик анкет



Программа читает анкеты студентов из файла anketa.txt, проверяет ФИО, почту,

телефон и группу, выводит таблицу корректных анкет, список отклонённых строк и

статистику по группам.

\## Структура проекта



\- main.py - точка входа: чтение файла, порядок действий, сохранение результатов

\- validators.py - проверки ФИО, почты, телефона и разбор строки анкеты

\- report.py - вывод таблицы и маскирование телефона

\- anketa.txt - пример входных данных

\## Запуск



python main.py

Нужен Python 3.8 или новее. Сторонние библиотеки не требуются.

\## Входной файл



Файл anketa.txt лежит рядом с main.py. Одна анкета в строке, четыре поля через

точку с запятой:

ФИО; почта; телефон; группа

Пример:

Иванов Иван;ivanov@example.com;+7 999 123-45-67;09С41

\## Результат



\- ok.txt - корректные анкеты

\- errors.txt - отклонённые строки с причиной ошибки

Эти файлы создаются при каждом запуске и в репозиторий не входят.
